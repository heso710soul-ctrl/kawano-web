# 河野智也｜お店のホームページづくり

仙台の飲食店・個人店向け「ホームページ作成・管理」のサイトです。

- `index.html` … ページ本体（文章はここを直します）
- `style.css` … デザイン（色は冒頭の `:root` で一括変更）
- `script.js` … スマホメニュー・お問い合わせ送信
- `image/` … 制作例のスクリーンショット・プロフィール写真

## お問い合わせフォーム
人材育成メンターのサイト（kawano-training-profile）と同じ Google Apps Script に送信します。
届いた内容は同じ Gmail・記録シート「河野智也サイト お問い合わせ記録」に入ります。
こちらからの相談は「ご相談の種類」が `HP：〜` で始まるので見分けられます。

## 制作例を増やすとき
`index.html` の「制作例」にある `<article class="work">…</article>` を1つコピーして、画像・文章・リンクを差し替えます。
