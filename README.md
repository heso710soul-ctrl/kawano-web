# 河野智也｜お店のホームページづくり

仙台のお店・個人事業向け「ホームページ作成・管理」のサイトです。

- `index.html` … ページ本体（文章はここを直します）
- `style.css` … デザイン（色は冒頭の `:root` で一括変更）
- `script.js` … スマホメニュー・お問い合わせ送信
- `image/` … 制作例のスクリーンショット・プロフィール写真

## お問い合わせフォーム
人材育成メンターのサイト（kawano-training-profile）と同じ Google Apps Script に送信します。
届いた内容は同じ Gmail・記録シート「河野智也サイト お問い合わせ記録」に入ります。
こちらからの相談は「ご相談の種類」が `HP：〜` で始まるので見分けられます。

## 制作例を増やすとき
`index.html` の「制作例」にある `<article class="work">…</article>` を1つコピーして、画像・文章・リンクを差し替えます。

## デザインについて（2026-10-11 再構築）
- 人材育成メンターのサイトと「兄弟」に見えるよう、ネイビー・文字の組み合わせ・吹き出しの形をそろえています
- 最初の画面の「やりとりの例」（吹き出しとスマホ）は、画像ではなく index.html の文字と style.css で描いています。お店の名前や文面は index.html の `exchange` の部分で変えられます（お店は架空の例です）
- 色は style.css 冒頭の `:root` で一括変更できます（voice.html も同じ色と部品を使っています）
- 再構築前の状態は `backup-before-rebuild-20261011` ブランチと、Googleドライブの「2026-10-11 デザイン再構築前（HP作成サイト kawano-web）」に保管しています
